# Default persona avatars

Generated using the built-in image_gen tool. Fictional adult portraits; stable persona IDs also apply to existing conversations. Assets are bundled with the frontend.

The UI imports 128 × 128 WebP derivatives (quality 82). The PNG files remain the design originals and are not imported by the application.

## Shared prompt

Create a square photorealistic avatar portrait of one fictional beautiful adult Chinese woman. Natural realistic skin texture, tasteful everyday clothing, soft daylight, close head-and-shoulders framing with entire head centered and generous margins suitable for circular crop. Attractive, approachable, individual facial features; polished editorial lifestyle photography, no text, no watermark, no border. Not based on a real person.
